## Monorepos and Turborepo

### What is monorepos?
A single repository that holds all you frontend, backend and devops code.
### Why monoreps?
- Shared code reuse
- Enhanced collaboration
- Optimized builds and ci/cd
- centralized tooling and configuration

### Common monorepo framwork in Node.js
1. Lerna
2. Nx
3. Turborepo
4. Yarn/npm workspaces
