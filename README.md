# 0-100 Cohort --- Full-Stack Web Development

**A complete beginner-to-advanced course**

The **0-100 Cohort** is a structured full-stack development course
designed to take learners from **0 to 100** --- starting with
programming and web-development foundations and progressing to advanced
backend engineering, frontend development, DevOps, system design, and
real-world projects.

## Course Roadmap

### Part 1 --- 0 to 1

![0 to 1 Course Syllabus](Syllabus%20for%200-1.png)

The first part builds the foundation required to become a full-stack
developer.

**Topics include:** JavaScript and its asynchronous nature, Node.js
runtime, SQL/NoSQL databases, MongoDB, PostgreSQL, TypeScript, backend
communication protocols, Express, ORMs, middleware, routing, Zod,
monorepos and Turborepo, serverless backends, OpenAPI, authentication,
React, state management, CSS, Tailwind CSS, Docker, Next.js, custom
hooks, AWS deployment, Nginx, reverse proxies, and practical projects.

### Part 2 --- 1 to 100

![1 to 100 Course Syllabus](Syllabus%20for%201-100.png)

The second part moves into advanced backend engineering, system design,
and DevOps.

**Topics include:** advanced backend communication, message queues and
Pub/Sub, proxies and load balancers, Redis, Kafka, design patterns,
database indexing and normalization, rate limiting, DDoS protection,
sharding, replication, resiliency, horizontal and vertical scaling,
polling, WebSockets, gRPC, capacity estimation, CAP theorem, testing,
WebRTC, Docker, container orchestration, Kubernetes, CI/CD, monitoring,
Prometheus, Grafana, serverless architecture, AWS services, and
real-world projects.

## What You Will Learn

By progressing through the cohort, you will move from **beginner-level
web development fundamentals** to building, deploying, scaling, and
understanding **production-grade full-stack applications and distributed
systems**.

The course combines:

-   **Foundations** --- JavaScript, TypeScript, Node.js, databases
-   **Backend Development** --- APIs, Express, authentication, ORMs,
    scaling
-   **Frontend Development** --- React, Next.js, state management,
    Tailwind CSS
-   **DevOps & Cloud** --- Docker, AWS, Nginx, Kubernetes, CI/CD,
    monitoring
-   **System Design** --- queues, caching, load balancing, scaling,
    resiliency
-   **Projects** --- end-to-end applications and real-world/open-source
    work
